# FORM · 人体绘画参考工具 — 功能与开发文档

更新日期：2026-10-06。本文描述当前实现，供继续开发、交接和验收使用。现有界面仍显示“人体结构研习室”；产品用途是生成绘画参考。

## 1. 产品定位

面向人体绘画、临摹和透视练习的交互式三维参考工具。用户调整同一人体姿势、观察角度、比例和灯光，在动态线、几何体、完整人体和轮廓线稿之间切换或并排比较，最后导出当前构图或全身参考图。

当前为纯前端静态应用。计算、项目载入和图片生成均在浏览器完成；没有账号、数据库、云端项目、多人协作或 AI 生成功能。项目文件需主动下载保存，刷新页面不会自动恢复工作。

## 2. 核心使用流程

1. 选择男性或女性模型，选择姿势预设。
2. 拖动关节点或修改关节角度，必要时开启 IK、镜像。
3. 选择单视图、四级横向并排或网格；选择同步或独立姿势。
4. 调整相机方向、焦距、距离和目标点，构图可只包含头部、上半身或其他局部。
5. 调整人体比例、灯光和空间辅助线。
6. 打开导出，检查实际预览，选择内容、取景、背景和分辨率，下载 PNG。
7. 需要继续编辑时，下载 JSON 项目文件，下次载入。

## 3. 页面与显示模式

顶部包含撤销、重做、保存姿势和导出入口。左侧工具栏切换姿势、相机、灯光、比例和辅助线面板。中央为三维画布、视角预设和显示模式。右侧为当前工具的参数；窄屏时参数面板移到工作区下方。

| 模式 | 表现 | 使用目的 | 内部 ID |
| --- | --- | --- | --- |
| 动态线 | 简化头部、关节点与骨架连线 | 观察动作、方向和比例 | 0 |
| 几何体 | 圆柱、关节球、胸腔与骨盆方块 | 分析空间朝向与透视 | 1 |
| 完整人体 | 具有蒙皮骨架的男女 VRoid 人体模型 | 观察人体表面、脸部和手足结构 | 4 |
| 轮廓线稿 | 可见表面轮廓、结构线及部分脸部细节 | 生成绘画线稿参考 | 5 |

旧的第 3、4 个中间阶段已从界面移除。内部保留六个槽位以兼容项目数据，不能把界面序号直接当作内部 ID。快捷键 1–4 对应四个可见模式。

并排模式支持四列和 2×2 网格；窄画布会使用网格。反转按钮调整显示顺序。独立模式仅分离各模式的姿势，相机、灯光、性别和比例仍共享。

同步开启时，编辑姿势应用到全部模式。关闭时，各模式从当前姿势获得独立副本。重新开启时，以当前选中的模式姿势覆盖其他模式，不能将它们自动合并。

## 4. 人体与姿势编辑

### 4.1 男女模型

完整人体和线稿分别使用女性 AvatarSample_A 与男性 HairSample_Male，不是同一个模型改标签。采用原生蒙皮权重、骨骼绑定和局部偏移，保留立体脸部、后脑、身体、手足。手指和脚趾为模型细节，目前没有独立的手指、脚趾编辑控件，也没有表情、发型或服装编辑器。

完整人体与线稿共享几何和材质，但克隆骨架，保证独立姿势不互相影响。模型加载期间显示状态；加载失败和 WebGL 初始化失败提供提示。

### 4.2 姿势预设

共 15 个：站立、走路、跑步、坐姿、伸展、战斗、蹲姿、回头、抬手、抱臂、跳跃、弯腰、趴桌、拿东西、靠墙。默认展示前 6 个，可展开全部。预设是静态姿势，名称不表示已有动作动画或场景道具；坐姿、趴桌、拿东西不会自动创建椅子、桌子或物品。

### 4.3 关节交互

可选择骨盆、腰部、胸腔、颈部、头部及左右肩、肘、腕、髋、膝、踝共 17 个编辑节点。面板提供三个局部角度轴；固定轴显示为固定。拖动节点使用观察相机建立交互平面。手腕和脚踝开启 IK 时采用双骨段求解，其他调整通过骨架旋转实现。

镜像开关和“左→右”“右→左”支持左右姿势复制，左右轴向符号转换后再次应用限制。另提供 C 型、S 型、反 C 型和后仰的脊柱预设。

### 4.4 关节范围

以下为代码中的局部 X/Y/Z 角度范围，单位为度。它们是绘画假人的保守编辑限制，不是医学活动度；正负号由本项目骨架坐标决定。

| 节点 | X | Y | Z |
| --- | --- | --- | --- |
| 骨盆 | -180～180 | -180～180 | -180～180 |
| 腰部 | -25～35 | -25～25 | -20～20 |
| 胸腔 | -20～25 | -35～35 | -20～20 |
| 颈部 | -20～25 | -30～30 | -20～20 |
| 头部 | -35～45 | -65～65 | -30～30 |
| 左肩 / 右肩 | -155～50 | -80～80 | 左 -25～170；右 -170～25 |
| 左右肘 | -145～0 | 固定 0 | 固定 0 |
| 左右腕 | -60～60 | -75～75 | -25～25 |
| 左髋 / 右髋 | -125～25 | -40～40 | 左 -20～50；右 -50～20 |
| 左右膝 | 0～145 | 固定 0 | 固定 0 |
| 左右踝 | -35～25 | -15～15 | -15～15 |

预设、面板编辑、拖动、镜像及项目恢复最终使用同一限制函数。肩部包含有限的锁骨跟随和手臂对躯干、头部的简化避让。当前不是全身碰撞求解器，没有脚底自动贴地、物体接触、重心平衡或物理模拟；极端动作仍可能穿模。

## 5. 相机、投影与构图

空白处左键旋转、右键平移、滚轮或双指缩放。视角预设有正面、侧面、背面、45°、俯视和仰视；“45°”目前采用约 35° 水平、8° 垂直角的三分之四视角。重置恢复默认目标、距离和 50 mm 焦距。

| 参数 | 当前范围 / 选项 | 行为 |
| --- | --- | --- |
| 投影 | 透视、正交 | 正交平行线保持平行；透视具有近大远小 |
| 水平角度 | -180°～180° | 环绕目标点 |
| 垂直角度 | -80°～80°（滑块） | 调整观察高度；轨道球交互上限略不同 |
| 距离 | 3～22（滑块） | 改变人体在画面中的大小 |
| 焦距 | 15～120 mm | 透视模式改变视场角；正交模式改变取景范围 |
| 焦距快捷选项 | 15、24、35、50、85、120 mm | 快速切换 |
| 透视强度 | 0～100% | 与焦距联动，当前是线性映射，不是额外独立参数 |
| 相机目标 | 头部、胸腔、腰部、骨盆、脚部、自定义 | 改变观察中心；支持手动平移 |
| 相机辅助 | 相机与目标线开关 | 在工作区显示辅助信息 |

滑块范围不等于所有手势输入的精确硬边界。自定义目标坐标面板范围为横向 -3～3、高度 0～5、纵深 -3～3。

所有视图、点击射线和当前镜头导出使用统一的投影与取景计算。并排视图为较窄单元格做适配；独立模式也使用共享相机。

## 6. 人体比例

头身比选项为 6、6.5、7、7.5、8，默认 7.5。腿长、肩宽、骨盆宽、臂长、躯干长的倍率范围均为 0.8～1.2，默认 1。恢复标准比例重置这些参数。

比例在四个模式间共享。简化骨架调整节点偏移；原生模型在绑定姿态基础上调整相应骨骼偏移与头部缩放。头身比是视觉控制参数，不是对变形后模型测量得到的精确头身数。大幅修改比例可能影响蒙皮外观。

## 7. 灯光与空间辅助

主光可通过轨道球或角度参数调整方向。光影预设包括正面、侧面、45°、顶光、底光、逆光、伦勃朗光和轮廓光。

| 参数 | 范围 / 上限 | 实现说明 |
| --- | --- | --- |
| 主光水平角 | -180°～180° | 围绕人体调整方向 |
| 主光高度角 | -80°～85° | 调整光源方向 |
| 主光距离 | 3～10 | 主光为方向光，距离不是点光的衰减半径 |
| 强度 | 0～6 | 调整主光亮度 |
| 柔和程度 | 0～3 | 调整阴影半径，效果受阴影映射实现影响 |
| 色温 | 3000～8000 K | 当前分暖色、近中性、冷色三个色段；非连续物理色温模型 |
| 辅助光 | 最多 2 个 | 固定位置的辅助光、轮廓光；可添加和移除 |

灰阶、强化明暗通过简化材质或环境 / 补光设置实现。原生 VRoid 材质及线稿后处理并非所有参数的逐一等效反映，不能把这些开关视为完整的摄影级着色流程。

辅助开关包括地面网格、透视网格（一点、两点、三点）、水平线、垂直线、人体中心轴、肩线、骨盆线、重心与重力线、人物包围盒。当前透视网格和重力线为绘画辅助示意，没有求解相机消失点或真实质量分布。所有操作辅助在导出时隐藏。

## 8. 轮廓线稿

线稿不是三角形网格线，也不是贴在模型正面的平面画。当前流程：

1. 将模型渲染到法线与深度缓冲区。
2. 比较周围八个采样方向，提取可见外轮廓和表面结构变化。
3. 使用原材质渲染中的深色部分补充眼睛等脸部细节。
4. 输出纸色背景或透明背景。

不可见背面不会直接产生透穿线。采样宽度系数为 0.65，并结合像素比与输出尺寸缩放。当前没有线宽滑块或 SVG 输出；这是基于模型的栅格线稿，不保证达到人工整理线稿的线条取舍和拓扑连续性。

## 9. 导出及真实预览

导出窗口中的 canvas 渲染实际内容，切换取景、模式、背景、布局与排序时重新生成预览。预览与 PNG 共用 outputCanvas 渲染路径，预览长边约 640 px；大图重新渲染，不是放大预览截图。

| 设置 | 选项 | 规则 |
| --- | --- | --- |
| 取景范围 | 当前镜头、完整身体 | 当前镜头保留角度、平移、缩放和所选视图的画幅比例；全身按变形后模型包围盒重新居中取景 |
| 内容 | 当前模式、指定四种模式之一、四模式拼图 | 拼图包含四个可见模式 |
| 背景 | 当前场景、白色、透明 | 当前场景为场景底色；地面、网格等辅助仍隐藏 |
| 分辨率 | 长边 1920、2560、3840 px | 按图像长边控制大小，不固定为 16:9，也不固定宽度 |
| 拼图 | 横向、纵向、2×2、自由排序 | 自由模式是拖动标签改变横向顺序，不是任意画布坐标摆放 |

在并排模式，“当前镜头”采用当前选中单元格的画幅与相机。需要大尺寸局部参考时，可先切换单视图再构图。拼图沿用所选单元格画幅；“完整身体”会为各模式分别计算取景，保持观察方向，含约 10% 留白。各模式比例略有差异时，单元格缩放可不同。

导出会隐藏关节点、相机和灯光标记、辅助线、地面网格及地面，不导出界面。拼图包含模式名称标签。输出 PNG，单图按模式命名，拼图为 FORM-study-sheet.png。高分辨率失败时提示降低分辨率后重试。

当前没有自定义矩形裁剪框；局部裁剪由相机取景完成。也没有 JPG、SVG、PSD、批量文件、视频或动画导出。

## 10. 保存、恢复与撤销

保存文件为 FORM-pose.json，外层包含 version: 2、app: FORM 和 state。state 保存共享及独立姿势、人体比例、性别、工具和模式、投影、相机位置与目标、灯光与辅助设置。

历史版本 1 的第 2、3 内部模式映射到完整人体，独立姿势数组扩展为六槽位。载入检查文件大小（不超过 100000 字节）、标识、版本、姿势数组、有限数值、关键参数范围和相机向量，失败显示提示；载入后应用关节限制。它不是完整的 JSON Schema 安全校验器。

撤销记录最多 60 个快照，重做使用独立栈。姿势、部分参数修改、导入等操作建立快照；不是每次工具切换、并排布局切换或 OrbitControls 手势都单独进入历史。快捷键 Ctrl Z、Ctrl Shift Z，数字 1–4 切换模式。

## 11. 技术结构与扩展入口

静态 HTML + CSS + 原生 JavaScript ES Modules，Three.js r180，使用本地 GLTFLoader、OrbitControls、SkeletonUtils。应用依赖浏览器 WebGL、Canvas、Pointer Events、ResizeObserver；响应布局使用 CSS 媒体查询和动态视口单位。

| 文件 / 函数 | 职责 |
| --- | --- |
| dist/index.html | 工具栏、工作区、参数面板容器、导出 / 帮助弹窗、模块映射 |
| dist/style.css | 桌面 / 窄屏布局、画布容器、控件与弹窗样式 |
| state、snapshot、applySnapshot | 状态、历史与项目恢复 |
| createRig、updateRig | 简化骨架及模式外观 |
| loadAnimeHead、updateAvatar | 实际加载完整男女模型、克隆骨架、动作映射与有限避让；函数名为历史遗留 |
| jointLimits、constrainPose | 统一关节范围 |
| studyCamera、canvasCoordinates | 视图、点击与当前镜头导出的投影计算 |
| renderStudy、inkPipeline | 正常渲染与轮廓后处理 |
| posedBounds、fullBodyCamera | 变形后顶点范围和全身取景 |
| exportPlan、outputCanvas | 拼图规划、预览与最终导出 |

后续扩展应保留内部模式 ID 的兼容处理，避免把原生绑定骨骼全部挪到简化假人的节点坐标；那会破坏肩部等区域的蒙皮。

## 12. 画布无限拉长修复

问题来自 canvas 内在绘图缓冲区尺寸参与 flex 容器布局，ResizeObserver 再依据变化后的容器调整缓冲区，导致反馈循环。

修复：画布绝对定位并填满 stage，脱离容器尺寸计算；stage 使用 flex: 1 1 0 和 min-width: 0。resize 忽略无效尺寸，将 CSS 尺寸取整；尺寸与像素缓冲区都未变化时不重复 setSize，但缓冲区意外失配时允许恢复。

注意不能移除画布的绝对定位，也不能只通过限制最大高度掩盖问题。比较布局的最小高度用于保证可读性，应与循环问题区分。

## 13. 本地运行与部署

GitHub 仓库：https://github.com/fqxxzyw/form-drawing-reference

```bash
python setup_resources.py
python -m http.server 8000 --directory dist
```

打开 http://localhost:8000 。Python 仅用于解包和本地服务，无第三方 Python 依赖。setup_resources.py 将 resources 中 Base64 分块拼成 ZIP，校验 SHA-256 后还原 vendor 与两套完整人体模型，不联网。源码直接提供，不需要 npm 安装或构建。不能直接用 file:// 双击页面。

静态服务部署需先运行资源还原脚本，再部署 dist。Sites 发布目录也为 dist，现有项目配置位于 .openai/hosting.json。GitHub 分发不包含该 Sites 项目绑定配置，避免复用者误绑定原网站。当前未配置自动 GitHub Pages 或 CI 发布。

## 14. 验证与验收

已完成：JavaScript 语法检查；画布尺寸回调回归检查；此前的男女模型 / 预设骨骼检查、透视与正交全身取景检查、拼图画幅一致性检查、EGL 轮廓 shader 与透明输出检查。当前环境没有可用的静态站浏览器预览，尺寸回归为逻辑检查，不能替代实际浏览器验收。

```bash
node --check dist/app.js
node tests/resize.cjs
```

手动验收建议：

- 桌面与窄屏中重复切换单视图 / 横向并排 / 网格，等待后画布尺寸保持稳定，底部按钮不持续下移。
- 拖动节点、切换全部预设与性别，正 / 侧 / 背面均有真实模型内容；极端动作检查肩、腋窝、手臂避让。
- 同步关闭后只修改一个模式，其他姿势保持；再次同步后以当前姿势统一。
- 近距离头部构图导出“当前镜头”应保持局部；“完整身体”应自动纳入全身。
- 白底和透明线稿、四种拼图布局、三种分辨率都可下载，图片不出现控件或地面网格。
- 保存后载入应恢复姿势和相机；错误文件应提示失败，不导致页面崩溃。
